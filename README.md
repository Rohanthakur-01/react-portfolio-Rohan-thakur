## ✨ Features

- ✅ **Responsive Design:** Works seamlessly on desktops, tablets, and mobile devices.  
- ✅ **Interactive Animations:** Engaging animations on scroll and hover for an enhanced user experience.  
- ✅ **Dynamic Content:** Projects, skills, and contact forms are interactive and functional.  
- ✅ **Smooth Navigation:** Easy access to all sections through a sticky navigation bar.  
- ✅ **Modern UI/UX:** Clean design with beautiful transitions and layouts.  

---

## 🛠️ Technologies Used

- **React** – Frontend library for building UI components  
- **Vite** – Lightning-fast frontend build tool  
- **CSS3** – Styling with responsive designs and animations  
- **Framer Motion** – Animation library for smooth transitions  
- **EmailJS** – For handling form submissions directly from the frontend  

---

## 📄 Sections Overview

### 🏠 Home

- Eye-catching introduction with a welcoming message.  
- Features **smooth scroll-triggered animations** and **hover effects**.  
- Navigation links lead to different sections of the portfolio.

---

### 👨‍💻 About

- Displays professional background, personal interests, and a brief summary.  
- Features a **downloadable resume** button.  
- Includes animations that appear on **scroll and hover**.  

---

### 🛠️ Skills

- Showcases technical proficiencies in various fields:  
  - **Frontend:** React, HTML5, CSS3, JavaScript  
  - **Backend:** Node.js, Express.js  
  - **Tools:** Git, GitHub, Vercel  
- Skill bars and icons animate when scrolled into view.  

---

### 📁 Projects

- Displays key projects with the following details:  
  - **Title and brief description** of each project  
  - **Technologies used**  
  - **Live demo links** and **GitHub repositories**  
- Projects **animate on hover** and display additional details.  

---

### 📞 Contact

- Functional **contact form** powered by EmailJS for direct communication.  
- Links to **LinkedIn**, **GitHub**, and other social profiles.  
- Smooth entry animations when the section is reached.
